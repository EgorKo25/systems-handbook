СОБСТВЕННАЯ GO-СЛУЖБА ДЛЯ ИЗУЧЕНИЯ DOCKER

Исходники: cmd/echo/main.go и main_test.go. Внешних Go-модулей нет.
Минимальная версия языка: Go 1.25; для основных контейнерных опытов выбирайте
поддерживаемый toolchain с нужными исправлениями и закрепляйте версию/digest.

Запуск не происходит при открытии книги. Полный последовательный маршрут:
../../index.html#16-integrated-lab. Установка Engine и официальный поиск:
../../index.html#01-install-and-state. Нужны свои разрешённые Linux/VM и Engine.

Сначала выберите официальный GO_IMAGE и сохраните его в паспорте. Из этого
каталога сборка:
  docker --context study buildx build --build-arg GO_IMAGE="$GO_IMAGE" \
    --platform linux/amd64 --load --tag study/echo:lesson1 .
Платформа должна соответствовать вашей среде. GO_IMAGE не имеет скрытого latest.
Базовый образ, Dockerfile frontend и будущие tools нужно подготовить до офлайна.

APP_ADDR: по умолчанию :8080.
APP_DATA_DIR: без значения счётчик отключён (HTTP 503), остальные маршруты работают.
С ним нужен существующий доступный UID 10001 каталог; том сам права не угадывает.
APP_CHECK_URL: URL режима /echo check; по умолчанию локальный /health на 8080.
GET /health: ok. GET /version: lesson1. GET /greet?name=...: JSON.
GET /counter: текущее число, POST /counter: увеличить с устойчивой записью.

Один писатель на каталог. Несколько экземпляров с общим файлом НЕ поддерживаются.
Счётчик не является транзакционной БД и не реализует безопасный повтор POST.
Устойчивость fsync/rename зависит от реального хранилища и его гарантий.
При синтаксически некорректной записи числа старт отказывает. При неопределённом исходе записи после
rename следующие записи блокируются до разбора и перезапуска.

Compose использует external volume study-data: сначала подготовьте его и права
по главе 16. Файл не создаёт PostgreSQL/Redis и не меняет их прежние экземпляры.
При новых упражнениях состояние не сбрасывают; down --volumes не требуется.

ПРОВЕРКИ ПРИ ПОДГОТОВКЕ
Go 1.27.3 linux/amd64, локальная временная рабочая область кэшей:
  go fmt ./...
  go test ./...
  go test -race ./...
  go vet ./...
  CGO_ENABLED=0 go build -trimpath -buildvcs=false -o ВРЕМЕННЫЙ_ФАЙЛ ./cmd/echo
Все перечисленные проверки выполнены успешно. Тесты проверяют сохранение/
повторное открытие числа, сериализацию 12 писателей одного процесса, отказ при
повреждении, отсутствие продвижения после отказа записи. Сетевой сервис на
хосте при этих проверках не запускался. Docker build/run/Compose и реальные
rootful/rootless/Windows/VM пути автоматически не проверялись: это ручной стенд.
