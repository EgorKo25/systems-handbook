Самостоятельный учебный HTTP-сервис на Go для книги о сборке и Jenkins.
Нет внешних модулей: после установки подходящего Go интернет не нужен.
Минимальная версия языка в go.mod — 1.25; проверяемая toolchain — 1.27.3.
Чтение библиотеки Go не требует. На рабочем компьютере ничего устанавливать
и запускать ради книги не нужно.

Скопируйте всю эту папку в отдельный собственный учебный репозиторий.
Инициализируйте Git и закоммитьте исходники, прежде чем проверять provenance.
Из корня копии:
  go test ./...
  go test -count=1 ./...
  go test -json ./...
  python3 tools/build.py
  ./dist/handbook-service -version
  go version -m dist/handbook-service

Python нужен лишь для записи и проверки метаданных учебной сборки.
Сам Go build внутри tools/build.py полностью указан в книге.
Если go отсутствует в PATH, задайте HANDBOOK_GO с абсолютным путём к bin/go.
Это не меняет настройки установленного Go. Кэш этого сборщика находится
в .lab-cache внутри копии проекта; сборщик отключает автоматическую загрузку
другого toolchain и обращение к прокси модулей. В данном проекте только stdlib.
Не переносите GOPROXY=off на проект с неподготовленными внешними модулями.

Артефакт dist/handbook-service (либо .exe) + dist/manifest.json.
Контракт: CGO_ENABLED=0, явные GOOS/GOARCH, -trimpath, -buildvcs=false,
фиксированная версия через -ldflags=-X. Git-ревизия записывается отдельно.
Это условия опыта, а не обещание совпадения байтов для любого Go-проекта.
Не сравнивайте бинарники разных toolchain/целей как одну и ту же сборку.

Для отдельного запуска HTTP:
  ./dist/handbook-service -listen 127.0.0.1:8087
  curl 'http://127.0.0.1:8087/greet?name=Go'
  curl http://127.0.0.1:8087/healthz
SIGTERM/CTRL-C запускает ограниченное по времени завершение.
Параметр name ограничен 128 байтами UTF-8, а не 128 символами.
Тесты обработчика не требуют открытия сетевого порта.
