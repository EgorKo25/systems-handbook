Практика самостоятельного тома Go

service/ — исходники небольшой HTTP-службы без внешних модулей.
Начните с service/README.txt; для чтения книги запуск не нужен.
Основной контракт проверен Go 1.27.3 на Linux amd64.
Сборка выполняется в вашей отдельной копии проекта и создаёт dist/.

check.py — семь интеграционных проверок с собственными временными копиями:
  HANDBOOK_GO=/путь/к/go python3 check.py
Если подходящий go уже в PATH, переменная HANDBOOK_GO не нужна.
Проверяются тесты приложения, бинарник, сведения о сборке, совпадение байтов
в разных каталогах, происхождение, изменение кода/версии и отказ пути-ссылки.
Результат сохранён в results.json. Windows не запускался.

toolchain-reference/ — сохранённая справка фактической версии Go и её лицензия.
Это первичные данные опыта; подробное русское объяснение флагов встроено
в карточки команд книги. Флаги внутренних инструментов зависят от версии,
а некоторые существуют только для определённых платформ и способов сборки.

Опыт с WORK/SSA/ассемблером находится в главе 59 тома Go. Он создаёт свои
учебные файлы; используйте отдельный каталог, не рабочий проект.
Кэш Go, временные каталоги и профиль также занимают место на компьютере.
На рабочем компьютере без разрешения на запуск инструментов достаточно
автономных текста, схем и сохранённых результатов. Настройки среды
через go env -w учебный маршрут не меняет.
