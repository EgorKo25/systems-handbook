Получение CLI, Java и драйвера

Проверяем выбранные байты и функции именно открытой поставки 13.12.0.

Версия и издание

CLI — интерфейс командной строки: короткоживущий процесс читает настройки, соединяется с базой, выполняет команду и завершается. JRE, Java Runtime Environment, исполняет Java-код этого процесса. JDBC, Java Database Connectivity, — интерфейс Java к драйверу базы. Драйвер PostgreSQL преобразует операции JDBC в сетевые сообщения PostgreSQL. Наличие Go на машине не заменяет JRE или JDBC.

На 1 ноября 2026 года официальный GitHub release flyway-13.12.0 опубликован 30 октября. Для Linux x86-64 выбран flyway-commandline-13.12.0-linux-x64.tar.gz, 384624596 байт, SHA-256 e332704f4bbb16baba4ac565a822ccb24354003a284deaa11668c1be77013c34. Сумма сверена с digest официального release asset и реально полученным архивом. При иной архитектуре этот архив непригоден; выбирают свой asset и его ожидаемый digest. Не заменяют номер в URL без повторной проверки.

Открытая сборка сообщает Flyway OSS Edition 13.12.0. Её Flyway-код распространяется по Apache 2.0; JRE, драйверы и дополнительные библиотеки имеют собственные лицензии. Архив Redgate с их сайта — отдельная поставка, способная содержать закрытые функции и требовать EULA/лицензию. Бесплатный режим Redgate и открытая поставка — разные составы файлов. Учебный маршрут не требует авторизации Redgate и не принимает EULA за читателя.

Личная установка без системных изменений

Следующий блок: Bash, обычный пользователь, cwd — домашний каталог. Предпосылки: Linux x86-64, заранее установленные curl, tar, sha256sum, доступ к официальному GitHub, достаточно диска. Каталог версии ещё не существует. Архив и исполняемые файлы остаются в личном $HOME/opt, вне каталога книги.

В Bash set -euo pipefail останавливает эту последовательность при отказе обычной команды, обращении к незаданной переменной или отказе участника конвейера. mkdir -p создаёт отсутствующие родительские каталоги; существующий downloads сохраняется.

set -euo pipefail
mkdir -p "$HOME/opt/downloads"
cd "$HOME/opt/downloads"
curl -4 --fail --location --connect-timeout 15 --max-time 300 \
  https://github.com/flyway/flyway/releases/download/flyway-13.12.0/flyway-commandline-13.12.0-linux-x64.tar.gz \
  --output flyway-commandline-13.12.0-linux-x64.tar.gz
printf '%s  %s\n' e332704f4bbb16baba4ac565a822ccb24354003a284deaa11668c1be77013c34 \
  flyway-commandline-13.12.0-linux-x64.tar.gz | sha256sum --check -
test ! -e "$HOME/opt/flyway-13.12.0"
tar -xzf flyway-commandline-13.12.0-linux-x64.tar.gz -C "$HOME/opt"
export PATH="$HOME/opt/flyway-13.12.0:$PATH"
flyway -v

--fail останавливает получение на HTTP-ошибке; --location следует официальному перенаправлению asset; -4 выбирает IPv4 и не отключает TLS. Проверка суммы должна дать OK, все команды — код 0. Ненулевая сумма, отсутствующий tar или уже занятый каталог останавливают блок до распаковки; ничего не «исправляют» пропуском проверки. Предупреждение об отсутствующей sql при -v не означает отказ Java: рабочая location будет задана проектом. PATH действует в этой оболочке; в новой его задают снова.

У curl --connect-timeout 15 ограничивает установление соединения 15 секундами, --max-time 300 — весь перенос 300 секундами, --output называет локальный файл. sha256sum --check - читает ожидаемую пару «сумма и имя» со stdin, заданную printf; ошибка суммы даёт ненулевой код. test ! -e требует отсутствия каталога версии. У tar -xzf означает извлечь gzip-архив из следующего файла, а -C выбирает каталог извлечения. Эти параметры меняют файлы личной установки, не создают базу.

В проверенном архиве находятся Temurin JRE 25.0.5+8 и drivers/postgresql-42.7.14.jar. Это наблюдение состава данного asset, а не обещание для ZIP без JRE или другой платформы. Файл драйвера не является сервером PostgreSQL. Для offline-дня сохраняют весь каталог версии с jre/, lib/, drivers/, licenses/, а не один shell-launcher. В launcher этой поставки первым проверяется FLYWAY_JAVA_CMD; иначе выбирается исполняемый jre/bin/java рядом с CLI. Только при отсутствии встроенной Java используются JAVA_HOME/bin/java либо java из PATH. Поэтому одного изменения JAVA_HOME недостаточно, чтобы заменить JRE полного архива. Перед переносом проверяют сам launcher и итоговый flyway -v.
