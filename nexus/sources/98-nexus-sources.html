Уточнения 2 ноября 2026

Повторная сверка GOAUTH для Go 1.27.3 подтверждает выбор NETRC, а раздел go mod verify — возможность получения go.mod для выбора версий. Python 3.12 selectors описывает ожидание готовности Unix pipe; Windows pipe этим способом не поддерживается. KillMode systemd относится к процессам конкретного unit. Это основания новых исходных рецептов, а не новые выполненные опыты Nexus, JVM или VM.

Чего источники не доказывают

Наличие API в общей reference не доказывает entitlement конкретной редакции, а feature matrix не проверяет ваши TLS/права/пути. Сборка Go с локальными fixtures не подтверждает Go hosted upload Nexus. Проверенный YAML/INI/nginx fragment не доказывает работу служб. Рецепты требуют VM приёмки и записи фактических ответов; локальная проверка не подменяет её.
