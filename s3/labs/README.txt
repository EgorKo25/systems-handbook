Лабораторные файлы S3

Начните из корня читательской копии библиотеки. Для этих проверок нужен
Python 3.12 или новее; внешние пакеты, сеть и учётные данные не требуются.

python3 -B s3/labs/sigv4_vectors.py
python3 -B s3/labs/object_operations.py
python3 -B s3/labs/storage_models.py check

Первая программа вычисляет фиксированные строки и подписи SigV4. Вторая
проверяет выбранные переходы истории одного ключа. Третья проверяет учебные
расчёты контрольных сумм, диапазонов, частей, списка и бюджета. Успешный
процесс завершается с кодом 0; нарушение проверяемого условия останавливает
его исключением. Эти модели не отправляют запросов S3.

Исходники отдельного Go-клиента находятся в s3/labs/object-client/.
Порядок подготовки, сборки и настройки адреса описан в главах 03–04 тома
и в s3/labs/object-client/README.md. До обращения к сервису подготовьте
свой учебный endpoint и ограниченный профиль доступа по этим инструкциям.
Проверка Python-моделей не подтверждает сборку Go-клиента, совместимость
SDK, TLS, права доступа или поведение выбранного сервиса.
