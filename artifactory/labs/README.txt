ARTIFACTORY: СОХРАНЯЕМЫЙ СОБСТВЕННЫЙ СТЕНД
Дата авторской проверки: 2026-11-01. Всё ниже написано для этого тома.

Чтение книги и схем полностью автономно. Получение клиентов, пакетов личной
VM и Artifactory — отдельный сетевой этап; ни один тест не устанавливает
службы или пакеты хоста. Artifactory не запущен автором. Pro X лицензия,
серверная VM, PostgreSQL, реальные права, promotion и restore не испытаны.

Скопируйте labs в постоянный собственный каталог, например
$HOME/artifactory-handbook/labs. Рядом заведите work/private (mode0700)
для собственных конфигураций и секретов. Не держите единственную копию
состояния в /tmp. Проверочные программы используют новые временные каталоги
и удаляют только созданное ими; постоянный учебный release и журналы читатель
хранит отдельно. Секреты, runtime и ключи не входят в публичную книгу.

ЗАВИСИМОСТИ ЛОКАЛЬНЫХ ОПЫТОВ
Linux amd64, Python3.11+ (stdlib), Bash, OpenSSL, tar, sha256sum; подготовленные
Go1.27.3, JFrog CLI2.129.0, ORAS1.3.6. Клиенты получают в главе01 собственными
recipes/get-cli.sh и recipes/get-oras.sh. Проверенная версия Go устанавливается
по тому Go; GO_BIN, JF_BIN, ORAS_BIN — абсолютные пути читателя к проверенным
файлам. Ни личные авторские пути, ни исполняемые файлы не включены.
Сетевые loopback-соединения и временные закрытые ключи создаёт только
local_checks; это собственный HTTP/HTTPS fixture, не сервер Artifactory.
Не запускайте этот опыт там, где политика запрещает даже loopback listener.

Из корня своей копии labs, после задания GO_BIN/JF_BIN/ORAS_BIN:
  python3 -B tests/local_checks.py --go "$GO_BIN" --jf "$JF_BIN" --report own-results.json
  python3 -B tests/guard_checks.py --report own-guards.json
  python3 -B tests/oci_checks.py --oras "$ORAS_BIN" --report own-oci.json

Эти три проверки используют только содержимое labs и заранее подготовленные
клиенты. Они доступны и в переносной читаемой копии (reading-export/Pages),
где авторского sources/ и volume_config.py нет.

Не продолжайте после ненулевого кода. Сохранённые tests/*results.json —
обезличенные результаты авторского запуска, а не обещание такого же времени
на другом железе. Публичные reports не содержат credentials, ключей,
частных адресов сервера или путей runtime.

ЧТО ПРОВЕРЯЕТСЯ
local_checks: настоящий Go получает свой модуль по протокольному fixture,
собирает receipt, проверяет вывод, повторный кэш и отказ без источника;
настоящий CLI сохраняет профиль с явно фиктивным секретом, обращается
к MOCK ping/curl, пишет go-config, накапливает build-info и делает dry-run.
HTTPS/NETRC проверяются Go, включая 401 без совпадения порта и без GOAUTH.
release_manifest проверяет обязательные metadata, непустые уникальные файлы,
размер/SHA256, отказ symlink и изменённых байтов. Это целостность относительно
отдельно принятого manifest, не независимое доказательство происхождения.
store_model — SQLite-модель ссылок/байтов и сборки мусора без настоящей схемы
Artifactory, транзакций между БД/FS, корзины, конкурентных писателей и HA.
oci_checks — настоящий ORAS в локальном OCI layout: digest manifest/layers,
получение по digest, отказ повреждённого и отсутствующего слоя. Registry,
контейнерный daemon и исполняемый образ здесь не создаются.
guard_checks — собственные stubs, подменяющие curl/sudo/tar только в новом
временном PATH: отказ HTTP/суммы до execution/extract. Это не установка.
cli_grammar — реальные --help, выбранные формы аргументов и dry-run:
не приписывает клиентскому принятию запроса серверный успех.
document_blocks — точный OpenSSL блок главы03 в новом каталоге, правильное
и неверное имя; статическая Bash-проверка неисполненных VM-рецептов.

ПРОДОЛЖАЕМЫЙ РЕАЛЬНЫЙ СЕРВЕР
Только своя VM. Сначала edition/entitlement/ресурсы, получение и проверка
поставки, затем recipes/extract-vm.sh. ВМ-профиль4vCPU/12GiB/80GiB —
учебный бюджет, не обещание размещения на8GiB host. При нехватке ресурсов
локальный путь выше остаётся завершённой самостоятельной работой.
recipes/system.yaml содержит явно заменяемый пароль, не действующий секрет.
Никогда не запускайте плейсхолдер как готовую конфигурацию.
recipes/nginx-api.conf обеспечивает API/Go/Generic; native OCI требует
отдельной сгенерированной конфигурации Repository Path Method (глава10).
fixtures/*.json — минимальные исходные намерения репозиториев, не выгрузка
проверенного сервера и не утверждение успешной проверки схемы API.
GitLab/Jenkins примеры не исполнялись: подготовленный личный агент,
защищённый токен через stdin, свой CLI home, отключённая трассировка.
Они передают один бинарник/build-info; полный manifest/approval/promotion
разобран отдельным шагом главы09, не автоматизирован этими минимальными файлами.
backup-vm.sh — неисполненный холодный резерв одного узла с default filestore
и одной выделенной PostgreSQL базой. Без другой топологии/писателей.
Восстановление только на новую изолированную VM, та же версия и весь
комплект БД+var+keys. Не храните резерв или globals.sql в этом публичном дереве.

ПРОХОД ИСХОДНИКОВ 2 НОЯБРЯ
TLS-блок главы03 сохраняет прежние CA/server files: повтор не создаёт новую
идентичность поверх старой. Блок Go publish главы08 прекращает выполнение
после ошибки cd/test/go-config. Restore главы14 создаёт сначала только роль,
а базу — один раз перед pg_restore. Две предметные inline SVG используют
прежние scene IDs; четыре остальные пошаговые схемы сохранены.
Новые SHA/h1/ZIP и численные примеры рассчитаны в памяти. Сервер, клиенты,
VM-рецепты и документированный OpenSSL-блок заново не запускались.
Старые reports ниже относятся к своему точному исходному комплекту1ноября,
их нельзя считать выполнением исправленных рецептов.

ПРОВЕРКА ИСХОДНИКОВ КНИГИ
Следующие дополнительные проверки требуют полного исходного checkout книги.
Production prepare_site исключает авторский sources/ и volume_config.py из
переносной копии/Pages. Поэтому cli_grammar читает reference.py, а
document_blocks — точный HTML-исходник; в reading-export они не запускаются.
Из artifactory/labs полного checkout:
  python3 -B tests/cli_grammar.py --jf "$JF_BIN" --oras "$ORAS_BIN" --report own-grammar.json
  python3 -B tests/document_blocks.py --report own-blocks.json

В полном checkout библиотеки, из корня repo:
  python3 -B artifactory/labs/tests/check_sources.py --render --report /СВОЙ/ОТЧЁТ.json
Рендер только в TemporaryDirectory, удаляется после проверки. Canonical
artifactory/build.py НЕ запускать авторским агентом: managed wrapper меняет
общие данные библиотеки. Интегратор отдельно включает CONFIG/targets в общую
сборку и проверяет общий parser/catalog/navigation. НомерXXIV предварительный.

ПУБЛИКАЦИЯ
Все fixtures, Python/Go/Bash, HTML и пошаговые схемы авторские. Сторонние
schema или библиотеки исходниками не включены. Runtime клиентов имеет свои
лицензии в отдельно полученной поставке; их бинарники здесь не распространяются.
Исходный checkout сохраняет sources/ и CONFIG. Переносная читаемая копия
сохраняет готовую книгу, справки и весь labs, включая необходимые dotfiles;
авторские sources/ и volume_config.py в неё не входят. Она исключает
work/private, __pycache__, архивы runtime, личные отчёты с конфигурацией.
