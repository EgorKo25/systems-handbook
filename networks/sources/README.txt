Авторитетные исходники сетевого тома

Исходные двадцать глав извлечены без изменения текста, ID разделов и лабораторий из проверенной версии 1 ноября 2026. reader-shell.html сохраняет действующую оболочку: справки, пакеты, рисунки, восемь тем и предпочтения. scripts/build_networks.py собирает только этот том; затем общее обновление словаря и настроек. Новые главы — такой же HTML; у каждой h2 постоянный уникальный id. Новые термины находятся в depth-glossary.json. Проверяемые вычисления — labs/theory-models.js, проверка node labs/check-theory-models.cjs.
