Синтетические учебные пакеты, не захват живого сервера.
.bin — полезная нагрузка DHCP/DNS; .frame — кадр Ethernet без FCS; .hex.txt — дамп полезной нагрузки.
PCAP содержит все 6 кадров, отметки времени условны.
DNS query 30 bytes; answer 46 bytes; flags answer 0x8500 (QR AA RD, RA=0).
DHCP client messages 300 bytes including padding; server replies 305 bytes (option 61 echoed per RFC 6842).
