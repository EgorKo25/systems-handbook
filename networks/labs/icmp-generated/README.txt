ICMP и IPv6: синтетические учебные примеры

Источник: пакетные байты вычислены автономной программой ../icmp-examples.py.
Это не захват реального сетевого обмена. Все временные отметки PCAP условны.
Последовательность объединяет независимые примеры, а не один реальный сеанс.

Формат:
- .bin — IP-пакеты целиком, начиная с байта версии IPv4/IPv6, без Ethernet.
- .hex.txt — те же байты с шестнадцатеричными смещениями.
- synthetic-icmp.pcap — 12 пакетов, классический PCAP, DLT_RAW = 101.
- inspection.json — проверенные поля и результаты проверки сумм.

Состав: IPv4-эхо запрос/ответ; исходный UDP; отказ порта; истечение TTL;
исходный UDP 1500 байт; ошибка о MTU 1400 с короткой цитатой;
ICMP-ошибка до и после обратного NAT; IPv6 NS, NA и DAD.
Цитата большого UDP содержит только начало: сумма UDP без полного исходного
сообщения не проверяется. Само полное сообщение приложено отдельно.

Из папки учебника:
python3 labs/icmp-examples.py
python3 labs/icmp-examples.py --output-dir /tmp/my-new-icmp-examples
python3 labs/icmp-examples.py --inspect labs/icmp-generated/fragmentation-needed.bin
tcpdump -n -vv -r labs/icmp-generated/synthetic-icmp.pcap

Каталог --output-dir должен быть новым; программа не перезаписывает существующий.
Python 3 и его стандартной библиотеки достаточно; сеть и root не нужны.
Для последней команды дополнительно нужен tcpdump. При подготовке он независимо
распознал все пакеты и подтвердил суммы полного UDP и ICMPv6.

Главы: ICMP / IPv6. Форматы RFC 792, 1191, 4443, 4861, 4862, 5508, 8200.
Ссылки и причинные объяснения находятся в тексте главы.
