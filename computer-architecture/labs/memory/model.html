Оригинальные конечные учебные модели. Переход — изменение объясняемого состояния, а не такт или измерение настоящей памяти. Код CPU не исполняется этой страницей. Начальное 42 находится по PA2000, результат 43 — по PA2200; профиль кэша: 16 B / 4 набора /одно место в наборе.
