По адресу PC машина читает команду из памяти. Декодер по коду команды выбирает микрооперации. Например, ADD складывает значения регистров в АЛУ, а ST записывает значение регистра в память.

Проверьте запись в память

      
В примере «42 → 43» дойдите до ST. В R0 уже 43, а по адресу 0x0080 ещё 00. Выполните ST и посмотрите, когда там появится 2B.
