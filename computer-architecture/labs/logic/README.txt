Локальные модели книги CPU

Откройте model.html обычным браузером из этого каталога. Рядом должны
сохраниться model.js/view.js и общий соседний ../m32/appearance.js.
Сервер, терминал и сеть не нужны. Программа и 512-байтный вход уже помещены
в массив памяти. Основной путь начинается с PC=1000 и числа 42.

«Следующая инструкция» исполняет одно логическое событие. «До события»
делает не более 16 шагов. После четырёх обычных инструкций выход RAM[2200]
содержит 43, а EBREAK на 1010 создаёт breakpoint и останавливает просмотр.
Счётчик попыток равен 5, принятых обычных инструкций — 4. В реальном CPU
EBREAK передаёт управление среде обработки; выключение/HALT не моделируется.

При повторном открытии продолжается собственное состояние из браузера.
Скачайте JSON для резервной копии/переноса; импорт проверяет его перед
заменой. «Явно начать заново» заменяет состояние только после подтверждения.
Если сохранение повреждено, Step/Run отключены; исходный ключ не стирается.
Исправную собственную копию можно импортировать или выполнить явный сброс.
Если браузер запрещает локальное хранение после явного сброса можно работать в памяти
вкладки и скачать JSON до закрытия.
Журнал хранит последние 1000 переходов; при обрезке сообщает число удалённых
записей и сохраняет исходную нумерацию. Полные счётчики попыток и принятых
инструкций, RAM, регистры и PC остаются в состоянии и JSON. После импорта
незавершённого состояния кнопки продолжают его с сохранённого PC.

Сначала показаны x0,x5,x6. Полный набор x0…x31 раскрывается через «Все 32
регистра» и всегда присутствует в JSON. Журнал показывает адрес команды,
байты, разобранные поля, чтение и изменения. Печать даёт текст шагов.

scenarios.html открывается отдельно. Это шесть ограниченных вариантов:
цикл BNE; вложенный вызов; тот же вызов без восстановления ra; переименование
A/B/C/D с успешной A; отказ A; двухбитный предсказатель. У цикла и вызова
разные таблицы кода, хотя обе начинаются по 1100. Их нет внутри основной
пятикомандной программы по 1000. Измените один описанный вход и нажмите
«Вычислить выбранную трассу». Сохраняются входы, из которых повторно строится
та же конечная трасса; прогресс model.html не затрагивается.

Тема и теплота общие с книгой: используются 8 существующих тем. Сцены можно
читать клавиатурой; широкая таблица прокручивается внутри рамки. JSON сцен
содержит входы и все вычисленные поля для независимого сравнения.

Эти модели не вычисляют электрические токи, CPU-такты или межъядерный
протокол. Пошаговые схемы глав показывают CMOS/сумматор/регистр, поля команд,
исходный путь 42→43, вызов, load-use stall, RAT/ROB и обучение предсказателя.
