Условия опыта

Сектор LBA 7 имеет 512 байт: 2A 00 00 00 и 508 нулей. DMA READ заполняет PA 2000..21FF. Отдельный интерфейс CPU-урока получает 42→43 и записывает только 4 байта по PA 2200. Перед WRITE размером 512 байт требуется явная подготовка оставшихся 508 байт. Volatile cache — энергозависимый кэш устройства. Durable здесь означает сохранение байтов после оговорённой потери питания. Завершённая запись в такой кэш ещё не даёт этой гарантии; flush, сброс на носитель, имеет своё завершение.

Здесь RAM когерентна DMA по явным условиям модели; нет модели кэша CPU, реальных PCIe TLP, NVMe SQE layout, планировщика, файловой системы и времени оборудования. «Потеря питания» ниже относится только к устройству: RAM оставлена для сравнения, а не изображает пережившую питание настоящую DRAM.

Передачи и границы

Другой порядок и ошибки

Здесь доступен каждый смысловой шаг. Неверный порядок даёт объяснение и оставляет байты без изменения. Изменения адреса и IOMMU предназначены для явного сравнения ветвей.

Кнопку «Опубликовать descriptor» используют отдельно после подготовки READ и WRITE. Неверный порядок даёт объяснение и оставляет байты без изменения. Для polling наблюдение completion возможно при маскированном IRQ: это показывает, что уведомление и наличие результата различаются.

Состояние путей

HOST: поля/OWN→Doorbell/контроллер→DMA/IOMMU → RAM→Completion → pending IRQ → CPU

Стрелки описывают зависимости. Мигающая анимация и цвет не используются как единственные носители смысла.

Журнал смысловых переходов
    Текстовый/печатный путь
    Подготовить READ → опубликовать → DMA READ → completion → IRQ при разрешённой доставке → наблюдать результат → ACK/возврат → CPU 42→43 и только 4 байта SW → отдельная подготовка 512 B → подготовить WRITE → снова опубликовать → DMA в volatile cache → WRITE completion → FLUSH request → FLUSH completion. Потеря питания до последнего шага оставляет устойчивое значение 42; после него устойчивое значение 43. Ошибки IOMMU не заменяют ни один буфер, IRQ masked не отменяет завершение.
