Закреплённая линия

Полный пакет Ansible 14 — отдельная поставка на семействе core 2.21. Практикум использует только core/ansible.builtin и авторский counter_config; внешних collection dependencies нет. Публичные ссылки latest могут со временем измениться: перед новой установкой сопоставьте их с pinned CLI docs и исходниками тега.

Что является исполнением

В этой редакции локальные тестовые образцы действительно запускаются на core 2.21.5 с временными файлами. Go-сервис проходит отдельные unit tests/vet/build в изолированной среде исполнения; Базовые HTTP handlers проверяются через httptest без слушающего порта; два принятых теста shutdown дополнительно открывают кратковременный listener 127.0.0.1:0 и закрывают его по завершении. Это локальные тесты helper, не проверка systemd или сигналов ОС. Диаграммы — фиксированные модели; условные performance-числа не выдаются за измерения. Multi-VM SSH/sudo/systemd/reboot/release/network-failure — рецепты и неисполненные критерии приёмки. Точные результаты и ограничения сохраняются в ПРОВЕРКИ.txt и READY.txt.

Том не заменяет эксплуатацию платформы секретов, гипервизора, балансировщика, БД или систему мониторинга. Он даёт проверяемые контракты на их границах. Неизвестное поведение новой коллекции или ОС проверяют отдельно; копирование команды с совпавшим названием не переносит автоматически её версионные гарантии.
