Ansible: оригинальный практикум

local/ — настоящий файловый стенд на local connection, два alias/два подкаталога.
vm/ — отдельный неисполненный рецепт двух собственных Linux VM.
service/ — авторский Go HTTP-сервис с сохраняемым count и tests без внешних зависимостей.
../tests/lab_check.py — реальный безопасный local прогон; ничего не устанавливает.

Начните с local/README.txt. Сохраняйте один учебный корень между упражнениями.
Автоматическая проверка создаёт свой отдельный временный корень; его cleanup
не является reset сохраняемого читательского стенда. Для VM требуется отдельно
прочитать vm/README.txt и принять SSH/Python/правила доступа.

Пути в документации — примеры; secrets, private inventory и бинарные runtime
в комплект не входят. Не запускайте privileged VM recipe на хосте пользователя.

requirements-core-2.21.5-linux-x86_64-py312.lock — точные версии/хеши9wheels
для проверенной Python3.12/Linux x86_64-платформы; wheels в public комплект
не входят. Сбор/проверка offline wheelhouse описаны в an-01-install.
