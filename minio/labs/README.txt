Лабораторные файлы MinIO

Рабочий каталог — корень читательской копии библиотеки. Python-модели
используют стандартную библиотеку и не запускают сервер MinIO:

python3 -B minio/labs/capacity_model.py
python3 -B minio/labs/healing_scanner_model.py
python3 -B minio/labs/object_io_model.py

Проверки завершаются с кодом 0 и выводят результаты фиксированных расчётов.
Они описывают выбранные учебные случаи ёмкости, healing/scanner и object IO;
не являются реализацией или тестом настоящего MinIO.

cold_copy.py — отдельное упражнение с файловой системой. Оно действительно
создаёт копию при действиях snapshot и restore. Перед использованием
прочитайте главу 10, остановите единственный учебный сервер и выберите
отдельное новое место назначения. Уже существующее назначение не заменяется.
Не применяйте программу к работающему серверу или к данным вне своего стенда.

В текущей проверке подтверждена передача ошибки обхода каталога через
модельный отказ os.walk. Настоящие файловые snapshot/restore, отключение
питания, MinIO/mc, TLS, IAM и работа кластера здесь не проверялись.
