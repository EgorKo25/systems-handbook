ЛАБОРАТОРИИ ТОМА «ОПЕРАЦИОННЫЕ СИСТЕМЫ»

Начните с ../index.html. Каждая глава сначала объясняет объекты и переходы,
затем предлагает изменить одно условие в модели или выполнить отдельный опыт.

ПАМЯТЬ И ФАЙЛЫ: memory-io/index.html
Перевод адреса, копирование при записи, очередь, распределение памяти,
вытеснение, сохранность имени файла и учебный журнал OSJ1. Для каждого опыта
заданы начальные данные. Кнопки показывают изменения модели в браузере;
они не меняют таблицы страниц и файлы операционной системы компьютера.
Подробности и безопасные нативные наблюдения: memory-io/README.txt.

КООРДИНАЦИЯ: coordination/index.html
Два увеличения одного числа, наследование приоритета, CAS, ABA,
публикация памяти, проверка условия и сон, взаимная блокировка, очередь,
уведомления, готовность ввода-вывода, проверка прав и бюджет процессора.
Выпадающий список выбирает опыт, второй — вариант. Изменение варианта
не является сбросом журнала. Повреждённое или неизвестное сохранение
сохраняется до вашего явного решения очистить собственный журнал.
Подробности: coordination/README.txt.

ИСПОЛНЕНИЕ И ПЛАНИРОВАНИЕ: execution/README.md
Модели кадров входа в ядро, ожидания, прерываний и планирования объясняются
в главах и пошаговых схемах читателя. execution/traces.json содержит
конкретные учебные состояния. Отдельной execution/index.html в комплекте нет.
Инструкции execution/README.md описывают и необязательные опыты Python
с собственными временными файлами. Чтение книги их не запускает.

ОБЩИЙ ПРИМЕР
trace-contract.json фиксирует формат counter.bin: 42 → 43, четыре байта,
младший байт первым. Параметры M32, адреса и имена участников принадлежат
конкретным моделям. Глава os-35-end-to-end связывает их, сохраняя различия
между вариантом in-place pwrite, заменой имени и журналом восстановления.

СОХРАНЕНИЕ И ПЕРЕНОС
Браузерные страницы хранят свой прогресс при доступном localStorage.
Копирование папки книги само по себе не копирует хранилище браузера.
Записывайте важные результаты отдельно и используйте предусмотренные
средства сохранения на соответствующей странице. Перед очисткой журнала
прочтите подтверждение: очищаются журнал и позиции выбранной лаборатории, не весь стенд.
Нативная папка упражнений и браузерная модель — разные места хранения.

РЕАЛЬНЫЕ ОПЫТЫ
Перед запуском native.py прочтите README выбранной лаборатории, укажите
собственный каталог и проверьте, какие файлы программа использует.
Утилиты не являются песочницей для произвольных чужих путей; например,
жёсткая ссылка может связать два имени с одним объектом. Для наблюдения
создавайте отдельные учебные данные, сохраняя результаты предыдущих шагов.
