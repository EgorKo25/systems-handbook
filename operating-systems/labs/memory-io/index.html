Память и I/O: измените одно условие

Это расчёты и конечные модели. Они не исполняют инструкции CPU, не открывают файлы компьютера и не измеряют устройство. Формат M32-2L-v1 придуман для учебника: 32-битные адреса, страницы 4 KiB, два уровня 10/10/12, 4-байтные записи с младшим байтом первым.

Записи таблиц и результат доступа

Значения записей задайте целиком. Биты 0–6: P/W/U/X/A/D/C, биты 7–11 обязаны быть нулями, 31–12 содержат номер кадра. У записи каталога D/C запрещены; права W/U/X на двух уровнях объединяются как И. C — программная отметка COW, а не разрешение аппаратной записи.

Для записи COW попробуйте leaf=0x0012a055. Затем снимите W только у directory: 0x0000900d. Наличие W у leaf не отменит запрет старшего уровня. Leaf=0 означает отсутствие; leaf=0x0012a087 нарушает зарезервированный бит.


Один кадр до записи, два после
Программа P уже прочитала число 42. Создайте второго владельца Q, затем запишите 43 от имени P. Копируется страница 4096 байт, хотя меняются четыре. После копии Q по-прежнему может иметь защищённый COW-перевод даже при единственном владельце старого кадра.

Бюджет отложенной записи
Считаем только накопление объёма при постоянных скоростях. Реальное ядро может объединять записи и ограничивать производителя раньше.


Видимость и модельная авария
Переходы: запись временного файла → fsync файла → rename → fsync каталога. Выбирается идеализированная локальная файловая система и честное выполнение sync нижним уровнем. Возможные исходы до последнего шага — только ограниченная учебная модель, не перечень всех повреждений настоящего накопителя.


32 кадра: разделить и объединить
Порядок k требует 2ᵏ соседних кадров. Выдайте несколько маленьких блоков; освобождение объединяет только свободных парных соседей того же порядка. Таблица показывает начала блоков, а не отдельные байты.


Один шаг вытеснения
A недавно читалась, B изменена, C закреплена, D не имеет подготовленной копии для восстановления. Нажатие «Проверить следующий кадр» делает ровно один шаг. Для B завершение записи — отдельное событие; новая запись во время ожидания сохранит dirty.
В выводе: resident — кадр ещё занят, ref — было обращение, dirty — есть несохранённая версия, pin — нельзя освобождать, writeback — запись ожидает завершения. Число 1 означает «да», 0 — «нет».


OSJ1: DATA без COMMIT не применяется
Исходный домашний блок 200 содержит 42. DATA7 описывает новое 43; лишь следующая корректная COMMIT7 позволяет восстановить 43. Эти кнопки добавляют модельные устойчивые записи, не обращаясь к диску.
Переключатель портит только копию байтов для расчёта. Ранее сохранённые записи модели остаются на месте; снимите его, чтобы сравнить результат.
