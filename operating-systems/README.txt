ОПЕРАЦИОННЫЕ СИСТЕМЫ

Откройте index.html обычным браузером. Том идёт после «Архитектуры
компьютера» и объясняет работу ОС перед разбором конкретных механизмов Linux.
Для чтения и браузерных моделей не нужны Интернет, сервер, Bash или Go.
Сохраните структуру папки вместе с labs/: страницы подключают соседние файлы.

Общий пример — counter.bin: число 42 становится 43, четыре байта записываются
младшим байтом вперёд. labs/trace-contract.json задаёт учебные адреса и
профили; эти числа не являются размерами или адресами вашего компьютера.
Порядок чтения, дополнительные опыты и их подготовка описаны в главах.

В labs/README.txt перечислены автономные модели и способы продолжить опыт.
Необязательные native.py выполняются только после подготовки, указанной
в README выбранной лаборатории. Они не запускаются при открытии книги.
Браузерное сохранение и личная папка нативного опыта хранятся отдельно;
перенос папки книги не переносит localStorage браузера.

SOURCES.txt содержит первичные ссылки, а ПРОВЕРКИ.txt — область проведённых
проверок и их ограничения. Для чтения не требуется запускать тесты. Часть
самопроверок моделей доступна и в переносимой копии; проверки исходных глав
требуют полной исходной копии репозитория и отдельно помечены в README лаборатории.
