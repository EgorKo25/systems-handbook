2. Основная лаборатория (реальное выполнение CLI)
Из корня репозитория, подготовленный binary в PATH:
python3 terraform/labs/check.py --terraform terraform
Для записи результата: добавить --report terraform/labs/check-results.json
Результат: 15 PASS. Полный перечень в check-results.json.
Одна продолжаемая цепочка собственного TemporaryDirectory, без reset после
ошибок; удаление только своей области после завершения:
- fmt/check, init, validate без внешнего provider;
- saved plan → apply → пустой detailed plan;
- изменение unmanaged rendered-файла даёт пустой plan (ожидаемый предел);
- explicit replace исправляет creation effect;
- input update сохраняет ID и НЕ перезапускает writer;
- moved service→node сохраняет оба ID;
- stale saved plan отвергнут после другого apply;
- конкурентный plan отвергнут во время настоящего local state lock;
- partial apply сохранил b2 у services и tainted у failed gate;
- fail_gate=false продолжил тот же state до пустого плана;
- lower serial state push отвергнут, force не использовался;
- явный snapshot/restore вернул source/state/files, прежняя область сохранена;
- plan JSON подтверждает delete/create и create/delete при lifecycle;
- prevent_destroy отвергает replacement;
- destroy выполнен только для terraform_data собственного временного state.
После добавления validations ключей/build тест повторён на итоговых исходниках.

8. Явные модели и неисполненное
Все DIAGRAMS — автономные пошаговые модели с символическими IDs,
не трасса байтов RPC и не настоящий runtime в браузере.
Не выполнялись: VM/hypervisor install, provider API create/update/delete,
remote backend/S3/HCP, облако/покупки, многооператорная удалённая эксплуатация,
SSH/Go-служба на гостях, full mirror для всех ОС/providers/modules,
upgrade/downgrade реального удалённого state, аварийное force-unlock/push-force.
Команды этих тем — рецепты для личной VM и review, не придуманные результаты.
Build wrapper, общий renderer, registration, export, commit и push не выполнялись.
Интегратор отдельно проверяет читательский HTML в изолированной копии.
