Лабораторные файлы инженерного практикума

Команды вида python3 labs/... выполняются из каталога textbook,
скопированного на отдельную учебную Linux ВМ. Установочные пакеты не входят
в эту папку. Никакие скрипты не нужно запускать для чтения HTML.

prepare-dns.py NEW_DIRECTORY
  Python 3.7+. Создаёт новый каталог с тремя конфигурациями named и зонами.
  Существующий каталог не перезаписывает. Не меняет системный DNS.
start-dns.sh DIRECTORY
  Bash + BIND. Проверяет конфигурации, запускает процессы на 127.0.0.1
  с портами 1053, 2053, 3053. При ошибке запуска останавливает свои процессы.
stop-dns.sh DIRECTORY
  Проверяет PID и аргументы named через /proc; останавливает только эти
  экземпляры. Конфигурации и журналы оставляет для разбора.

prepare-kdc.py NEW_DIRECTORY
  Python 3.7+. Создаёт krb5.conf и kdc.conf для нового учебного realm LAB.TEST.
  Базу KDC, пользователей и keytab создают вручную командами из главы.
  Системные /etc/krb5.conf и /etc/krb5.keytab не трогает.

network-up.sh
  Root в отдельной учебной ВМ. Создаёт course-c, course-r, course-s и veth.
  Отказывается использовать существующие одноимённые namespaces.
  При ошибке удаляет только созданные текущим запуском пространства.
network-down.sh
  Удаляет три учебных namespaces. Сначала остановите tcpdump и другие
  процессы внутри них; при наличии процессов скрипт откажется удалять.
  Не предназначен для любых других одноимённых объектов.

postgres-lab.sql
  Только новая отдельная course_db и администратор тестового кластера.
  Создаёт схему course, три NOLOGIN-роли и две таблицы в одной транзакции.
  Отказывается работать с другой БД или существующей схемой.
  Запуск через psql -X -v ON_ERROR_STOP=1 -f labs/postgres-lab.sql.
  Очистка описана в главе PostgreSQL; автоматического удаления данных нет.

packet-example.py NEW_OUTPUT.pcap
  Python 3.7+, стандартная библиотека. Создаёт один синтетический
  Ethernet/IPv4/UDP/DNS кадр с рассчитанными checksum. Ничего не отправляет.
  Отказывается перезаписывать существующий файл.
example-dns.pcap
  Готовый результат генератора. Можно открыть в Wireshark.

Проверенные сценарии и ограничения: ../validation.txt.
