Версии, лицензии и матрица не взаимозаменяемы

Release notes 8.0 содержат дату патча и advisories; официальная матрица клиента помогает планировать совместимость. Статическая HTML-выгрузка матрицы не отдала таблицу, поэтому конкретный нижний предел Go/Server в томе подтверждён README/go.mod самого тега v2.9.2. Реальное подтверждение пары8.0.34+2.9.2 — native test, а не заявление о проверке всех ячеек матрицы. Stable API ограничивает поддержанные команды/поведение в заявленной версии API, но не отменяет compatibility notes и миграции приложения.

MongoDB Community — SSPL-1.0 (полный официальный текст); driver, mongosh и Database Tools имеют Apache-2.0 с собственными уведомлениями. Копии лицензий и происхождение — в NOTICE. Enterprise Advanced/Atlas и их функции не являются автоматически частью Community. Встроенные auditing и encrypted storage engine относятся к Enterprise; сертификаты TLS и внешний шифрованный диск не превращают Community в Enterprise.

Карта первичных механизмов

  • Установка: Ubuntu tarball, integrity/signature, server configuration, TLS configuration.
  • Данные: BSON grammar, BSON types/ObjectId, wire protocol, driver implementation tag.
  • Хранение: WiredTiger, journaling, serverStatus.
  • Планирование: explain results, compound, multikey, partial, unique, TTL, aggregation limits.
  • Согласование: write concern, defaults и arbiter exception, read isolation/causality, retryable writes, Go transactions.
  • Распределение: oplog, elections, rollback, shard key.
  • Эксплуатация: dump behavior, restore options, upgrade/FCV/downgrade limits.

Что не доказано этим томом

Реально исполнены один local authenticated replica set, BSON/array/null semantics, Go CRUD/migration/index/transaction, сохраняющий restart, logical backup и restore на другой loopback endpoint, TLS положительный и отрицательные сценарии. Проверены помощь CLI и production parser справочника. Не исполнялись multi-host elections/rollback/network partition, sharded cluster/resharding, live oplog/PIT/physical snapshot, major upgrade/downgrade, физическая потеря питания, Enterprise/Atlas workflows и performance под production concurrency. Их механизмы объяснены с обозначенными ограничениями; документация не выдаётся за результаты установки.

Сохранённые отчёты: native JSON, TLS JSON и журнал проверок. Это синтетические учебные данные, не внешняя телеметрия. Схемы не эмулируют MongoDB, не обращаются к сети и доступны вместе с исходниками офлайн. Перенос книги не равен готовой автономной поставке server/runtime/modules.

Что уточнено и выполнено 2 ноября

Новый JSON-reader сервиса дочитывает тело до EOF. Его 13 native Go unit cases с -race проверяют неизвестные поля, второе значение, мусор, границу 4096/4097 байт и длину UTF-8; listener и MongoDB для этих 13 случаев не запускались. Четырнадцатый тест проверил ожидание активного HTTP-обработчика при остановке на собственном временном loopback listener без MongoDB. Отдельный новый экземпляр 8.0.34 на loopback проверил усиленный ACTION=types: четыре ожидаемых множества ID, отказ повтора без перезаписи и сохранение четырёх документов; экземпляр штатно остановлен, временные файлы удалены. Эти результаты и точные source SHA находятся в новом отчёте.

Две предметные SVG показывают собственные байты OP_MSG и диапазон индексных ключей из seed, заменяя два общих графа. Python-декодер и арифметика в mechanisms.py работают без сервера; это не перехват, не B-tree-симулятор и не benchmark. Старые native/TLS/concurrency JSON сохранены без приписывания им нового SHA сервиса. Полные seed/restore/TLS и 16 клиентов после уточнений JSON-reader и shutdown не повторялись. Нативная растеризация SVG и проверка палитр не считаются запуском reader в браузере или фактической печатной пагинацией.
