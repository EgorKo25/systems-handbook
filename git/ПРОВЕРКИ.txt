ГРАНИЦЫ
Все перечисленные опыты локальны и используют отдельные временные данные.
Реальные внешние SSH/HTTP-серверы, Git LFS, git-filter-repo, Windows,
X.509/OpenPGP и все виды подписей не проходили полный практический прогон.
Разделы различают подтверждённые опыты и механизм по документации.
Справочник объясняет выбранные формы, а не все параметры всех команд Git.
Короткие A/B/C — символические обозначения вершин, не вычисленные хеши.

Git имеет собственный автономный практикум labs/ с Python-шаблоном,
иллюстрирующим историю и воспроизводимость ZIP. Основной Go-проект вынесен
в отдельный том go/labs/service; Jenkins — jenkins/labs. Это разные проекты
с разными командами и контрактами. Старые ссылки из общего тома переводят
к перенесённым главам. Заметки старого тома не удаляются.

Лаборатории нужны Git 2.28+ и Python; прогон — Python 3.12.3.
Запрет установки и запуска на рабочем компьютере не требуется обходить:
весь текст, справки, словарь и схемы читаются автономно в браузере.
