Том VI: Git и воспроизводимая сборка. Редакция 31 октября 2026.

Это самостоятельный учебный текст с собственными примерами, схемами и проектом.
Фрагменты находятся в sources/, сборка: python3 scripts/build_library.py
из корня репозитория. Для чтения сборка и интернет не нужны.

ПРОВЕРЕНО
— 52 теста автономной лаборатории: python3 git/labs/check_lab.py.
  Реальный Git 2.43.0 и Python 3.12.3 на Linux; временные каталоги,
  семь связанных опытов, восстановление контрольных точек, защита границ,
  сравнение байтов и метаданных воспроизводимого ZIP.
— 19 отдельных опытов механизмов Git при вычитке глав 01–13.
— 9 опытов сборки, измерений и обработки статуса оболочки; ещё 9 проверок
  согласованности кода проверки Jenkinsfile с фактическим учебным шаблоном.
— 11 нетривиальных форм команд справочника проверены настоящим Git.
— Три Git-схемы воспроизведены на настоящих временных репозиториях;
  числа и ключи в трёх схемах сборки рассчитаны из объявленных входов.
— Фактический JavaScript поиска команд, составные имена и ссылки данных
  схем проверяет node git/labs/check-reader.cjs.
— Общий scripts/check_site.py проверяет локальные ссылки, якоря, встроенные
  словари/справки, JSON и синтаксис JavaScript. Он не заменяет вычитку смысла.

ГРАНИЦЫ
Jenkins и Maven не запускались. Их конфигурации разъясняют механику;
они требуют подходящих инструментов/плагинов и настройки окружения.
Windows не проверялся. Командный маршрут практикума использует Bash;
запрет установки на рабочем компьютере не нужно обходить ради упражнений.
Справки охватывают применённые формы и не заменяют полные руководства Git.
Демонстрационные A/B/C и другие короткие имена вершин — условные обозначения,
не реальные хеши; точные вычисленные хеши подписаны отдельно.

Общий словарь встроен в каждый том и работает через file:// без загрузки сети.
Для офлайн-практики сохраните всю папку git/labs, включая template/.gitignore.
Лаборатория не требует Docker, SSH и сетевого сервера. Нужны установленные
Git 2.28+ и Python; реализация использует API Python 3.8+, но прогон выполнен
только на 3.12.3. Общие сборщики библиотеки требуют Python 3.10+.
